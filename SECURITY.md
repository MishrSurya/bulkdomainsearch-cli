# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability within `bulkdomainsearch-cli` or the underlying RDAP client implementation, please do not file a public GitHub issue.

Instead, please send an email directly to:
**ads@bulkdomainsearch.si**

Include detailed reproduction steps and logs. We acknowledge reports within 48 hours and coordinate patches prior to public disclosure.
